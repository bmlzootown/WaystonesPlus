## Getting Started

To get started with WaystonesPlus, follow these instructions to install and configure the plugin on your Minecraft server.

### Prerequisites

- PaperMC Server (26.1.2)
  
### Installation

1. Compile/package jar file and move it into the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Usage

### Commands
- /wsp help
- /wsp get [Waystone type] [Name] (Requires waystonesplus.command.get permission)

### Spawn item
Just place it anywhere in the world. (Requires waystonesplus.placewaystone permission)
If you want to place it less than 50 blocks from each other you need permission for that. (waystonesplus.distanceoverride)


### Waystone
To interact with the Waystone, just right click on it. (Requires waystonesplus.interact)

### Permissions

See the [plugin.yml](https://github.com/bmlzootown/WaystonesPlus/blob/master/src/main/resources/plugin.yml).

Please make sure to configure these permissions accordingly in your Minecraft server's permission system.
